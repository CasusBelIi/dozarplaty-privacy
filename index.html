Настоящая Политика конфиденциальности описывает, какие данные могут обрабатываться при использовании мобильного приложения «До зарплаты - учет расходов» (далее — «Приложение»), для каких целей они используются и каким образом обрабатываются.

Используя Приложение, пользователь принимает условия настоящей Политики в части, применимой к использованию Приложения.

3. Данные, которые пользователь вводит самостоятельно

Приложение позволяет пользователю вводить:

  • текущий баланс;
  • дату следующей зарплаты;
  • сумму расхода;
  • категорию расхода;
  • необязательный комментарий к расходу.

Эти данные используются для учёта расходов, расчёта доступного бюджета и отображения информации внутри Приложения.

4. Хранение финансовых данных

Приложение не требует создания учётной записи и не подключается к банковским счетам или банковским операциям пользователя.

Данные, необходимые для работы функций учёта расходов, хранятся локально на устройстве пользователя. Разработчик не получает доступ к введённым пользователем суммам расходов, балансу или комментариям через сервер Приложения.

5. Реклама

В Приложении используется рекламный сервис Yandex Mobile Ads SDK.

Рекламный SDK может обрабатывать определённые данные устройства и идентификаторы для показа рекламы, измерения её эффективности и предотвращения злоупотреблений.

В зависимости от настроек SDK и устройства пользователя могут обрабатываться рекламные идентификаторы и техническая информация, необходимая для работы рекламного сервиса.

Данные, обрабатываемые рекламным SDK, могут передаваться соответствующим сервисам Yandex в рамках предоставления рекламных функций и измерения рекламы. Передача данных осуществляется по защищённому соединению.

Подробнее об обработке данных рекламным SDK можно узнать в документации Yandex Mobile Ads.

6. Местоположение

Приложение «До зарплаты - учет расходов» не использует геолокацию пользователя для своей основной функциональности и не запрашивает доступ к точному или приблизительному местоположению для расчёта бюджета или учёта расходов.

7. Передача данных третьим лицам

Разработчик не продаёт введённые пользователем данные о расходах или бюджете третьим лицам.

Передача определённых технических данных может происходить через сторонний рекламный SDK Yandex Mobile Ads в рамках предоставления рекламных функций и измерения рекламы.

8. Безопасность

Разработчик принимает разумные меры для защиты данных, используемых Приложением. Финансовые данные учёта расходов хранятся локально на устройстве пользователя и не передаются разработчику через сервер Приложения.

Передача данных сторонним рекламным SDK осуществляется с использованием защищённых механизмов связи, предусмотренных соответствующим SDK.

9. Удаление данных

Пользователь может удалить данные учёта расходов средствами Приложения, если соответствующая функция доступна, либо удалить данные Приложения через настройки Android.

Удаление Приложения с устройства удаляет локально хранящиеся данные приложения в соответствии с механизмами Android.
